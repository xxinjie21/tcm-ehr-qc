# 质控提升计划：导出件标准化率（最高目标）

> **最终验收口径：导出数据集（POST /api/export/dataset，只导出质控合格且已清洗的病历）里，实体原文落在标准词表（标准词或别名）的比例。**
> 导出机制：standardizeMap 把每条文本里归一命中的 sourceText 就地替换成标准词；原文已是标准词的实体不触发替换动作，但本身已标准化。真正口径 = 原文是否已是标准形态。
> 数据时点：2026-10-20 仅归一后实测（34182 提交 / 34154 完成 / 93 永久失败）。
> 本计划两条线：归一率提升（决定导出件能被标准化多少）+ 抽取正确率（决定归一对不对）。

## 二、抽取正确率（边界与归属）

### ④ 四类形态归属判断（已定案 2026-10-20）

按中医语义 + 实测数据，四类「疑似问诊」形态的归属判定：

| 类别 | 代表词（频次） | 归属 | 依据 |
|---|---|---|---|
| 面色 | 面色萎黄561 / 潮红79 / 白61 / 晦暗53 | **症状** | 望诊体征，词典已有标准词 |
| 进食 | 纳差435 / 食欲差390 / 食欲一般842 | **症状** | 中医药学标准症状词 |
| 睡眠 | 多梦1146 / 入睡困难895 / 失眠149 | **症状** | 病理性症状，词典标准词 |
| 便尿·病理 | 尿色黄1735 / 便秘510 / 便溏359 / 小便频数426 | **症状** | 标准症状词 |
| 便尿·描述 | 大便日一行1182 / 成形490 / 小便平311 | **问诊** | 二便常态描述，非病理 |

**结论：不能按「含问诊词」一刀切迁走。** 病理性发现（面色萎黄/便秘/便溏/失眠/多梦/纳差/尿色黄）必须留 symptoms；只有描述性整句（二便/睡眠常态描述）归 inquiry。

**对 _reroute_inquiry 的含义**：现有锚词偏宽，会误迁病理性标准词。需收紧为「仅描述性整句」并排除词表病理性标准词。

### ⑤ 程序缺陷：西医诊断列漏回补（已完成，637 test 全绿）

- 现象：质控疾病来源含 westernDiagnosis，但回补只传 tcmDiagnosis
- 修法：backfillDiseases 合并中西医两列 scan；backfillFromRaw 新增 6 参重载；NlpBatchServiceImpl 传入 westernDiagnosis
- **生效条件**：该修复在重抽/批量抽取时生效，仅归一不重跑回补；存量 1422 条需重抽后体现

### ⑥ _reroute_inquiry 归位：判定为【不执行】（保护导出替换）

**实测证据（合格病历）**：`_reroute_inquiry` 宽锚命中 24843 条，其中：

| 影响 | 条数 | 说明 |
|---|---|---|
| **会损失导出替换** | **7830** | 搬走 = 少 7830 次「原文→标准词」替换 |
| 中性（搬不搬无影响）| 17013 | 本就没有标准词可替换 |

损失样例（这些已能产生高价值替换，搬走即亏）：
```
面黄 → 面色萎黄 (424)
梦多 → 多梦 (823)
夜寐难入睡/入睡难 → 入睡困难 (638)
小便色偏黄 → 小便色黄 (373)
```

**结论：`_reroute_inquiry` 按现方案是「纯亏」操作** —— 损失 7830 次导出替换（拉低标准化率），而中性部分搬走也不产生任何收益。**不执行、不在仅归一链路启用。**

（若将来重做，必须：先查症状词典命中则不搬 + 只搬 truly 无标准词的纯描述，且逐条验证不损失替换。）

## 四、验收口径（稳妥、可验证）

1. 最终验收：导出数据集（合格+已清洗）里实体原文落标准词表比例
2. 每次改动自查：mvn clean test 全绿 / 前端 build / API 实测
3. 程序改动只提交不推送（推送需明确指示）
4. 指标同一分母比（34182/34154/93）
5. 归一率与抽取正确率分开汇报，不混为一谈
6. 宁可少补不错补；口径不明不动抽取
7. 报告类改动验证先清 Redis 缓存（tcm:ehr:cache:stats:report:*，TTL=REPORT_TTL*10=30min）
8. 豆包每批补词后：落库-重建ES-仅归一-量测，反馈给豆包

### 判断修正：症状不做「抽取噪声过滤」

**原计划要做的「把脉诊手法/舌诊专名/病程诱因从 symptoms 移走」，经实测判定不做：**

| 理由 | 数据 |
|---|---|
| **收益极小** | 零损失可移 3821 条 → 症状归一率 54.5% → 约 55.5%（+1pp）|
| **对最高目标零贡献** | 移走的都是未归一/原样实体，不产生导出替换 |
| **风险不小** | 类别内混真症状（按之不痛=腹诊体征、纳差=标准词、流清涕=真症状）|
| **成本高** | 改抽取规则 + 重抽 1 小时 |

**症状 54.5% 的真实归因（已写进审计报告）：**
- 词表已饱和（豆包五轮扫描 14461 词补入 0 个）
- 未归一主力是抽取错位噪声（脉诊手法/舌象碎片/问诊整句/属性词），不是词表缺陷
- 剩余可提升空间 ≈ 1pp

**⇒ 症状按现状认定为「真实水平」，不再投入。**

### 治法：数据里无治法内容

**实测：全库 34154 份病历中，仅 2 处文本含「治以/治宜/治法/治则」。**
- 治法抽取率 40%（5 条实体）不是规则问题，是数据里没有规范治法表述
- 治法词典 1214 词功能完好，词本身在病历里出现过 520 次（散落在证候/现病史句子中）
- **⇒ 如实标注为「数据缺失」，不关归一、不改规则**

### 质控规则：保持严格，不调参

**影响分析结果（模拟调权）：**

| 方案 | 合格率 |
|---|---|
| 基线（核心 12 分/项，术语 1 分/条）| 84.3% |
| 核心×0.5 | 89.6% |
| 核心×0.4 | 96.1% |
| 术语×2.0 | 81.0%（降）|

**决定：规则不动。** 理由：降核心权重到 0.4 能让合格率到 96%，但那是「调参调出来的」而非数据变好 —— 病历本身仍缺内容（78.6% 的核心缺失是原始病历没写）。**保持严格、真正诚实。**
