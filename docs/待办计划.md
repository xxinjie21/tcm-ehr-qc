## 前端显示规范（批K）

**原则**：一句一个事实、精确到原因；不叠 toast；不写"系统异常，请稍后重试"这类空话；状态就地展示。

任务状态文案：

| 状态 | 显示 |
|---|---|
| QUEUED | 排队中（前面 N 个任务） |
| RUNNING | 进行中 300/35355 · 成功 X 失败 Y |
| COMPLETED | 已完成：成功 X，失败 Y |
| CANCELLED | 已取消（已处理 X，剩余未处理） |
| INTERRUPTED | 已中断（服务重启），可重跑 |
| FAILED | 失败：<精确原因> |

失败原因（精确到根因，禁用泛化）：

- 抽取服务未开启（`nlp.enabled=false`）
- 抽取服务连不上（:8001 未启动）
- 术语索引不可用（ES），归一无法完成
- 该病历无可抽取的文本字段
- 其余取后端 `msg`，不套前端兜底文案

按钮文案即动作：开始 / 取消 / 重跑。失败清单可展开、不刷屏。
