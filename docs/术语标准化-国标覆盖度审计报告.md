# 术语标准化 · 国标覆盖度审计报告

> 审计日期：2026-10-20
> 数据时点：34154 份病历（仅归一后实测，含豆包五轮补词成果）
> 审计目的：回答「各类术语归一率是否达到行业标准」

---

## 一、核心结论

### 1. 不存在官方的「术语归一率」量化标准

查阅权威文件后确认：
- **国家中医药管理局《中医病案质量控制中心建设与管理指南（试行）》(2020)**：对术语的要求是**定性**的，仅规定「填写应当使用**规范的**疾病、证候诊断和手术操作名称」，**未设定任何归一率百分比阈值**。
- **不存在「术语归一率 ≥X%」的官方验收指标。**

因此「是否达到行业标准」在官方层面**没有数字可对照**。能对照的是「国家标准术语集的覆盖度」与「实际归一表现」。

### 2. 症状没有国家标准

**国标不设独立症状标准**。可用的是：
- GB/T 47335.1-2026《中医药 诊断词汇 第1部分：舌象》（2026-03-31 发布，2026-07-01 实施，采用 ISO 23961-1）
- GB/T 47335.2-2026《中医药 诊断词汇 第2部分：脉象》
- GB/T 20348 中医基础理论术语；GB/T 42467-2023（9 个临床各科）

**⇒ 「症状归一率 53.9% 是否达标」在国标层面无法对照。**

## 四、症状 53.9% 归因分析（关键）

**症状是唯一显著短板，但责任不在「词表缺陷」：**

1. **词表已饱和**：豆包五轮扫描症状候选 14461 词，最终**补入 0 个** —— 候选几乎全命中负面清单（不受按/红多点/不痛/大便每日）
2. **未归一的主力是抽取错位噪声**：
   - 脉诊手法：`不受按`、`中取不受按`、`沉取`
   - 舌象碎片：`红点多`、`有红点`
   - 问诊整句：`大便日一行`、`小便平`、`夜寐一般`
   - 属性/性状：`偏黄`、`浑浊`、`欠利`
   - 病程/诱因：`活动后缓解`、`遇劳加重`
3. **⇒ 症状 53.9% 反映的是「抽取边界问题」，不是「术语标准化能力不足」。**

## 五、总体判断

**已有结论：具备「可用于临床科研数据集」的水准。**

- **有国标的临床诊断核心（疾病 88.1%、证候 78.5%）**：词典覆盖 95%-106%，实际归一良好 → **可自信对标国标**
- **中药/脉象/舌象（93.7%-99.5%）**：超出一般水平
- **症状 53.9%**：国标无对照基准；其低值是抽取边界问题，修正方向是抽取迁移而非补词

## 七、审计方法说明

- **国标术语数**：取自项目《医学术语词典资源清单》与国家中医药管理局公开信息
  - GB/T 16751.1-2023 疾病 1369；GB/T 16751.2-2021 证候 2060；GB/T 16751.3-2023 治法 1276；系列合计 4705
- **词典规模**：直接读取 `java-backend/src/main/resources/dictionaries/*.json` 的 `standardTerm` / `aliases` 计数
- **实际归一率**：扫描全库 `structured_data`，统计 `normLevel != null` 的实体占比
- **覆盖度局限**：未能获取国标全文逐条比对，覆盖率按「标准词数量」估算，非逐条匹配
