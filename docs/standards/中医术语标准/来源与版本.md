## 六、转换工具（已有，勿重复造）

`tools/convert-standard-pdf.py`（已入库跟踪，批A·1.4 产物）：

- `TYPE_TO_FILE` 只有 **5 类**（disease／pattern／symptom／herb／formula），**同样没有治法**。

- 默认只打印校对清单，**加 `--write` 才覆盖词库**。
- 别名分隔符 `[、,，;；|/\s]+`，与后端 import 切分口径一致。

> **已解决（2026-09-28）**：给该脚本加了 **DOCX 支持**（新增 `from_docx()` 与 `--section N`），因为 docx 是结构化 XML，比 PDF 抽表稳、别名也能稳定取到。现在 PDF 与 DOCX 都能吃。

### 7.3 关键决策：合并，不是替换

**直接替换会退步**（实测）：

| 类型 | 只换国标词 | 合并 |
|---|---|---|
| 疾病 | 51.3% | 51.3% |
| 证候 | **78.5%（退步）** | **100.0%** |
| 症状 | **10.1%（退步）** | **22.5%** |

原因：现有 30 条证候／20 条症状是**按本数据集措辞手挑的**（`肝气郁结`／`横逆犯胃`／`胃脘胀痛`），而国标是规范证名与症状名（`肝胃不和证`／`水肿`）。替换会丢掉对数据集措辞的覆盖。
→ 采用**旧词在前、国标词在后**的合并，旧词优先，保住已手挑的别名。

### 7.4 证候的解析源

证候由**《中医临床诊疗术语 第2部分：证候（修订版）》docx** 解析（gov.cn 直链，见第一节来源地址），**不是**本目录那份国标 PDF —— 因为该 PDF 是正式出版版式、抽表不稳，而 docx 的条目体例（编号 → 标准名 → 别名 → 定义）可稳定解析。
那份 docx **未留在本目录**（避免同类重复）；需要复现时按第一节地址重新下载即可。国标 PDF 作为**现行版留档**保留。

### 7.5 别名去撞车（已处理）

国标里**类目词**会把成员词当别名（`消渴类病` 别名 `消渴`、`痹证类病` 别名 `痹证`、`不寐病` 别名 `不寐`）。
一级精确按列表顺序取**首个**命中 → 若别名与另一条目的标准词相同，结果会取决于词条顺序（脆弱）。
处理：转换时丢掉「与其它条目标准词撞车」的别名（疾病丢 1 条），合并后再消一次 → **撞车归零**。类目词本身保留（它们是国标正式条目，且其别名是合法来源）。

### 7.6 残留风险

1. **症状仍只有 22.5%** —— 国标症状性术语仅 51 条，覆盖不了数据集里 `神疲乏力`／`食少纳呆`／`腹胀便溏` 这类描述性短语。要提升只能补《中医诊断学》或名词委词表。
2. **5 条包含命中偏短**：`鼻黏膜淡白水肿 → 水肿`。不影响计分正确性，但信息有损（这是既有「取最短」规则的固有行为）。
3. **中药 240 条未命中未解决**（截断成 `天`／`失` 那批），需按 `§9.2` 第 ④ 步从原始列回补。
