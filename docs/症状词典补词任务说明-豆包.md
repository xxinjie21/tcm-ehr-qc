# 症状词典补词任务说明（豆包）

## 一、你要做什么

把「真实病历里抽出来、但症状词典没收录」的规范症状词，补进症状词典。

**目标不是把未归一的词都收进来，而是把「真正是症状」的词正确收进来。**

当前基线（2026-10-20，仅归一后实测）：

| 项 | 数值 |
|---|---|
| 症状实体总数 | 198030 |
| 已归一 | 78763（39.8%） |
| 未归一 | 119267（60.2%） |
| 未归一 去重词数 | 57803 |

症状是质控扣分第一大来源（计分 5 类合计未归一 151806 条，症状独占 119267，占 78.6%）。所以补症状词表是当前性价比最高的工作。

---

## 二、词典文件格式（必须严格遵守）

文件：`java-backend/src/main/resources/dictionaries/symptoms.json`

```json
[
  {
    "standardTerm": "失眠",
    "aliases": ["不寐", "不得眠", "不得卧", "睡不着", "失眠多梦"]
  }
]
```

规则：
1. **根节点是数组**，每项必须恰好包含 `standardTerm`（字符串）和 `aliases`（字符串数组）。
2. `standardTerm` 是**标准词**，只能是规范的医学术语，不能是口语。
3. `aliases` 收**同义变体**（口语、简写、语序变体、近义说法），可以为空数组。
4. 文件必须合法 UTF-8 JSON，不能有 BOM、注释、尾逗号。
5. 标准词之间**不能重复**；同一别名**不能挂在两个不同标准词下**。

## 三、判断标准：什么该补，什么绝对不能补

### ✅ 该补（按优先级）

**第 1 档：部位 + 症状的复合词（优先级最高）**

现有词典已有 113/535 个这类词（如 `双下肢水肿`、`下肢怕凉`、`口中异味`），照此惯例补。

实测高频例子：
- `咽喉不适`(76)、`胃脘不适`(74)、`扁桃体肿大`(71)、`咽弓赤络`(68)、`左少腹压痛`(57)、`脐右压痛`(53)、`脐左压痛`(52)、`乳房胀`(54)、`咽喉堵塞感`(48)、`咽壁淡红`(48)

**判定**：部位词（咽喉/胃脘/脐左/左少腹/乳房/咽后壁…）+ 症状/体征，整体是一个独立临床发现。
注意：`咽喉痛` 和 `咽喉不适` 是两个不同发现，各自登记，不能合并。

**第 2 档：口语 / 俗语症状 → 登记为标准词的别名**

实测高频例子：
- `上下楼梯特别疼`(50)、`蹲下去站起来都费劲`(50)、`膝盖酸酸的没力气`(50)、`人越来越瘦`(50)、`浑身没力气`(50)、`遇劳加重`(48)、`脾气很急`(39)、`遇烦恼则痛作或加重`(36)

**判定**：这些是病人原话式描述，**不是标准术语**。要找到对应标准词，登记为**别名**。

参考映射（最终以你的医学判断为准）：
- `上下楼梯特别疼` / `膝盖酸酸的没力气` / `蹲下去站起来都费劲` → 可能归到 `膝痛`、`腰膝酸软`、`下肢痿软` 一类
- `人越来越瘦` → `消瘦`
- `浑身没力气` → `乏力`
- `遇劳加重` → 病程特点，需医学判断（可作对应症状别名或独立标准词）

**第 3 档：确实缺的标准症状词**

判断方法：与现有 535 个标准词逐个比对，确认现有词典确实没有近义词，才新增 `standardTerm`。

### ❌ 绝对不能补（补了就是错映射）

**① 脉象/舌象要素（不属于症状）**
- 脉诊手法：`不受按`(228)、`中取不受按`(115)、`左不受按`(55)
- 舌象碎片：`红点多`(225)
- 规律：以 `脉/舌/尺/寸/关/苔/边/尖/根` 开头，或含「不受按/应指/中取/浮取/沉取」

**正确处理**：这些应由抽取层归位到脉象/舌象字段，不是症状词。

**② 属性词 / 性状词（不是独立症状）**
- `偏黄`(74)、`浑浊`(85)、`淡黄`(51)、`黄褐色`(60)、`偏粘`(70)、`欠利`(67)
- 规律：以 `偏/略/较/稍/微/甚/淡/浓/浑/清/稠/稀/多/少` 等程度或性状字开头

**为什么不能补**：把 `偏黄` 收成标准词，会让所有含「偏黄」的实体（面色偏黄/小便偏黄/痰偏黄）全部误归，语义错乱。

**③ 问诊子项（不是症状）**
- `大便日一行`(469)、`大便成形`(410)、`大便一日一次`(352)、`小便色略黄`(216)、`饮水多`(175)、`食量一般`(168)、`食欲欠佳`(166)、`夜寐一般`(148)、`晨起小便淡黄`(100)
- 规律：二便/睡眠/饮食/饮水/精神/面色/喜恶类描述

**正确处理**：这些是「问诊」子项，程序已移到 `inquiry` 字段（重抽后生效），不是症状。

**④ 否定式 / 已愈表述**
- `不痛`(145)、`未见异常`
- 例外：现有词典确有 `无汗`、`不能平卧` 两个否定式标准词，说明**病理性否定**可作为标准词登记（如「食欲欠佳」）。
- **但**：`不痛` 这种**对症状的否定**（病人说没有）绝不能收 —— 收了等于把「没有」记成「有」。

**⑤ 截断残片**
- `食欲一`(134)、`小便色`(80)、`有时`(75)、`夜寐`(93)、`俯卧`(87)、`仰卧`(82)
- 这些是抽取截断的中间产物，补了会让抽取器合法输出半截词。

**⑥ 部位名词（缺少症状部分）**
- `咽喉`(43)、`唇暗`(49)、`尿酸` —— 单说部位不是症状，需部位+表现。

## 四、别名规则（重要）

1. **别名长度 ≥ 2 字**。单字别名只参与精确命中、不参与包含匹配，且极易误伤（历史上 `质软→脉软`、`吐痰→呕吐` 就是单字别名造成的错映射）。
2. **不收残片**：`小便色`、`夜寐一` 这类截断词不能做别名。
3. **复合发现独立成词**：`腋下汗出` ≠ `汗出`，部位不同的发现各自登记，不能当别名合并。
4. **否定式发现登记为标准词，不做别名**：`食欲欠佳` 这类病理性否定应作为独立标准词（参考现有 `无汗`）。
5. 同一别名不能挂在两个标准词下。

## 九、候选清单与二次甄别（重要）

我已导出一份高频候选清单：`docs/症状补词候选-高频2000.csv`

| 列 | 说明 |
|---|---|
| frequency | 该词在 34154 份病历中出现的次数 |
| candidate_term | 候选词原文（从病历里抽出来的） |

**这份清单是「机器粗筛」的结果，不是「合格待补清单」。** 我用的过滤规则只能排除最明显的几类，但实测前 60 名里仍然混着不该补的词。举例：

| 混进来的词 | 实际是什么 | 为什么不该补 |
|---|---|---|
| `中取不受按`(115)、`左不受按`(55) | 脉诊手法 | 属脉象，不是症状 |
| `黄褐色`(60)、`晨尿偏黄`(59)、`晨尿略黄`(59) | 颜色性状 | 不是独立症状 |
| `活动后缓解`(71)、`休息后缓解`(62)、`活动后减轻`(50) | 病程特点 | 不是症状本体 |
| `日一行`(46) | 问诊残片 | 被截断的「大便日一行」 |
| `右小紧左乏力`(44)、`右较左有力`(43) | 脉象描述 | 属脉象 |
| `按之痛`(45)、`按之不痛`(43) | 触诊手法 | 需判断是否属体征 |

**所以请你对清单里的每一个词做二次甄别**，按第三节的标准判断：

- 是**独立临床发现** → 补
- 是**属性/性状/病程/手法/残片** → 不补，记入 skip 清单

**宁可少补，不可错补。** 错一个词会污染所有含该子串的实体，比不补的危害大得多。
