### 2.4 由实测反推的 6 个根因（按严重度）

1. **导出替换无长度下限、无边界** —— 单字 `有`/`血` 全文替换，一条病历就能改坏 66 处（`GovernanceServiceImpl.java:968`）。
2. **清洗二次归一以 content 为输入且无否定护栏** —— 非幂等 + 语义反转（`GovernanceServiceImpl.java:460/489`，对比 `EntityNormalizer.java:498`）。
3. **包含级判定无长度/边界保护** —— 标准词方向、别名方向都是裸 `contains`（`EsTermNormalizer.judge:246`）。
4. **一级判定按"逐条目 std→alias"顺序** —— 更短的精确标准词会被更长的别名条目抢走（`心悸 → 心悸手抖`）。
5. **抽取侧无任何产物过滤** —— 单字、否定 span、化验名、医院名直入结构化数据（`nlp_model._flush:326`）。
6. **模糊级对"子串关系"没有否决（高精度目标的最后一个漏点）** —— 即使包含级被 R1–R4 拦住，
   只要候选与输入构成子串关系，三级 Dice 仍会命中：`dice("脚气","干脚气")=2×2/(2+3)=0.8 ≥ 阈值`、
   `dice("藿香","广藿香")=0.8`、`dice("湿热下注","湿热下注证")=0.889`。于是
   **R2/R4 单独用不够** —— 必须新增 R7，把"子串等价"彻底交给别名表（C3）。

  - `nlp_filters.drop_noise(resp: ExtractResponse) -> Dict[str, int]`（返回各字段丢弃计数）

**现状与证据**：`_flush`（`nlp_model.py:326`）把 BIO 解码出的每个区间直接产出，`nlp_rules._rules` 的产出也直接 extend（`main.py:70-72`）。实测因此产出 `细胞角蛋白19`（dosage=19片）、`江西省`、`江西中` 三味假药，`有`、`血` 两个单字，以及 6 条否定句阳性症状。

**判据（三条，各自独立可测）**

| 判据 | 规则 | 反例（必须拦住） | 正例（必须保留） |
|------|------|------------------|------------------|
| F1 单字 | `len(span) < 2` → 丢（4 类无词典字段） | `有` `血` `双` | 单字标准词交给 Java 侧精确命中，不再依赖本判据 |
| F2 鬼词 | 中药 span 必须全部汉字、长度 2~5、不以机构后缀结尾、不含检验语素、不以省份简称开头 | `细胞角蛋白19`(含`蛋白`+数字) `江西省`(以`省`结尾) `江西中`(以`江西`开头) | `岷当归` `土茯苓` `益母草` |
| F3 否定 | span 自带否定词 **或** 前 6 字窗口含 `无/未/否认/未见/无明显/排除` → 丢；`NEG_KEEP` 里的"不X"规范说法除外 | `反酸` `嗳气` `打嗝` `恶寒` `脚气` `无黄汗` | `不寐` `食欲不振` `大便不畅` `睡眠欠佳` |

**F3 的取舍（必须先说清）**：否定症状在临床上是有意义的（"否认口干口苦"），但当前 schema 没有 `negated` 字段，保留它只有两个坏下场 —— 要么被归一成阳性症状（语义反转），要么算作未归一并扣分（实测 `EntityNormalizer:485-501` 的注释已承认这一点）。**本计划选丢弃**：原文列一字不动，信息不丢，只是不进入结构化字段。要保留"否认"的语义需给 schema 加 `negated`（见 §13 被否方案），不在本期范围。

```python
"""抽取产物的产物级过滤（不依赖模型、不依赖词典，纯形态与语境判据）。

为什么放在 Python 侧而不是 Java 侧：这些 span 是 NER 的**原始输出**，越早剔除，
后面的归一、扣分、导出替换全都少背一份噪声。Java 侧的 `dropSingleCharFragments`
只认识「词典里有没有」，对「细胞角蛋白19」这种不在任何词典里的鬼词无能为力。
"""
from typing import Dict, List, Optional

from schemas import ExtractResponse

# ---- F1 单字 ------------------------------------------------------------------
# 只对无独立词典的字段（病因/治法）与长度判据；舌/脉/症状/疾病/中药/方剂的单字
# 交给 Java 侧按「是否精确命中词典」处理（词典里确有单字标准词，一刀切会误删）。
_SINGLE_CHAR_FIELDS = ("symptoms", "diseases", "patternList", "causeList", "treatmentList")

# ---- F2 中药形态 --------------------------------------------------------------
# 机构/检验语素：出现即不是药名（都是实测把院名、化验项抽成中药的元凶）
HERB_STOP = ("蛋白", "细胞", "抗原", "抗体", "片段", "细菌", "病毒", "基因", "激素",
             "免疫", "检验", "检查", "结果", "报告", "医院", "大学", "学院", "研究院",
             "研究所", "中心", "妇保", "门诊", "科内", "系列")
# 省份简称：`江西省` / `江西中`（后者是前者的截断）都以它开头
PROVINCE_HEADS = ("北京", "上海", "天津", "重庆", "河北", "山西", "辽宁", "吉林", "黑龙江",
                  "江苏", "浙江", "安徽", "福建", "江西", "山东", "河南", "湖北", "湖南",
                  "广东", "广西", "海南", "四川", "贵州", "云南", "陕西", "甘肃", "青海",
                  "内蒙古", "新疆", "西藏", "宁夏", "香港", "澳门", "台湾")
HERB_MIN_LEN, HERB_MAX_LEN = 2, 5


def _all_cjk(s: str) -> bool:
    return bool(s) and all("\u4e00" <= ch <= "\u9fff" for ch in s)


def is_plausible_herb(span: str) -> bool:
    """中药名的形态合理性：全汉字、2~5 字、无机构/检验语素、不以省份开头。"""
    span = (span or "").strip()
    if not (_all_cjk(span) and HERB_MIN_LEN <= len(span) <= HERB_MAX_LEN):
        return False
    if any(w in span for w in HERB_STOP):
        return False
    if span.startswith(PROVINCE_HEADS):
        return False
    return True


# ---- F3 否定 ------------------------------------------------------------------
# ⚠️ 判定集合刻意**不含** 欠/缺/忌/禁/寡：「睡眠欠佳」「纳欠佳」「忌口」是规范写法，
# 词自身就带这些字，收进来会把正常症状当否定句误删（实测「睡眠欠佳」会被删）。
NEG_HARD = ("无", "未", "莫", "非", "否认", "未见", "无明显", "排除")
# 「不X」里 X 属于这些语素时，是**规范说法**（症状名本身带「不」），不能当否定句
NEG_KEEP_TAIL = ("寐", "适", "安", "宁", "固", "化", "和", "利", "扬", "仁", "遂", "孕",
                 "消", "佳", "畅", "眠", "食", "欲", "得", "解", "知", "足", "均", "能",
                 "受", "育", "明", "振", "规", "思", "运", "痛")
# 回看的上限（防超长文本 O(n²)）。真正决定「看到哪」的是**分句界**，不是这个长度。
NEG_WINDOW = 30
# 回看时遇到这些**分句界**就停：否定词不跨分句作用。
# ⚠️ 刻意**不**把顿号「、」当界 —— 「无 A、B、C」里 A/B/C 同属一个否定辖域，
# 把顿号当界会让枚举里靠后的项（打嗝）逃过否定判定。
NEG_BOUNDARY = "。；;！？，,:：\n"


def _has_normative_bu(span: str) -> bool:
    """span 里的「不」是否属于规范说法（食欲不振 / 大便不畅 / 不寐）。"""
    for i, ch in enumerate(span):
        if ch == "不" and i + 1 < len(span) and span[i + 1] in NEG_KEEP_TAIL:
            return True
    return False


def _span_self_negated(span: str) -> bool:
    """span 自身带否定词（规范「不X」除外）。"""
    if any(w in span for w in NEG_HARD):
        return True
    return "不" in span and not _has_normative_bu(span)


def _negated_before(text: str, pos: int) -> bool:
    """pos 之前、**同一分句内**是否有否定词（顿号不隔断辖域；分句界截断）。"""
    ctx = text[max(0, pos - NEG_WINDOW):pos]
    cut = -1
    for i in range(len(ctx) - 1, -1, -1):
        if ctx[i] in NEG_BOUNDARY:
            cut = i
            break
    if cut >= 0:
        ctx = ctx[cut + 1:]
    return any(w in ctx for w in NEG_HARD) or ("不" in ctx and not _has_normative_bu(ctx))


def _all_positions(text: str, span: str) -> List[int]:
    """span 在 text 里出现的全部位置（用于「所有出现都须是否定才算否定」）。"""
    out: List[int] = []
    i = text.find(span)
    while i >= 0:
        out.append(i)
        i = text.find(span, i + 1)
    return out


def is_negated_span(span: str, text: str = "", start: Optional[int] = None,
                    end: Optional[int] = None) -> bool:
    """该 span 是否处于否定语境。

    ① span 自带否定词（非规范「不X」）→ 是；
    ② 给了 (text, start) → 只看该处；
       只给 text → 看**全部出现**，要求「每一处都在否定语境」才算否定
       —— 同一个词若既有肯定用法又有否定用法，不能整条删掉。
    """
    span = (span or "").strip()
    if not span:
        return False
    if _span_self_negated(span):
        return True
    if not text:
        return False
    if start is not None:
        return _negated_before(text, start)
    positions = _all_positions(text, span)
    if not positions:
        return False
    return all(_negated_before(text, p) for p in positions)


# ---- 统一入口 -----------------------------------------------------------------
def drop_noise(resp: ExtractResponse, full_text: str = "") -> Dict[str, int]:
    """就地过滤抽取结果，返回各字段丢弃条数（供日志/报表对账）。

    `full_text` 给了才做「窗口否定」判定（由 is_negated_span 自行定位 span 出现位置）；
    只给 span 的调用点仍走「span 自带否定」这一半。
    """
    counts: Dict[str, int] = {}
    for field in _SINGLE_CHAR_FIELDS:
        items: List = getattr(resp, field) or []
        kept = [e for e in items if len((e.content or "").strip()) >= 2]
        counts[field] = len(items) - len(kept)
        setattr(resp, field, kept)
    # 症状：再过滤否定（传全文，函数内部定位每一处出现）
    symptoms = list(resp.symptoms or [])
    kept = [e for e in symptoms
            if not is_negated_span(e.content or e.sourceText or "", full_text)]
    counts["symptoms"] = counts.get("symptoms", 0) + (len(symptoms) - len(kept))
    resp.symptoms = kept
    # 中药：形态过滤（丢了的连着 dosage 一起丢）
    herbs = resp.herbs or []
    kept_h = [h for h in herbs if is_plausible_herb(h.name or h.sourceText or "")]
    counts["herbs"] = len(herbs) - len(kept_h)
    resp.herbs = kept_h
    return {k: v for k, v in counts.items() if v}
```

| **R5** | （复用 `TermGuard`）否定语境下不认包含/模糊命中 | `无黄汗→黄汗` —— 抽取侧有护栏、清洗侧没有，见 Task 5 |
| **R6** | 一级判定分两轮：先跨全部候选找 `std==input`（多条取最短 std），再找 `alias==input`（多条取最短 std） | `心悸→心悸手抖`（`心悸` 本身是标准词，却被更早召回的 `心悸手抖` 的别名抢走）、`知饥→知饥不食` |
| **R7** | 模糊级（三级）也否决「子串关系」：候选的 `standardTerm` 或任一别名与输入**互为子串**时，该候选不参与 Dice 打分 | `脚气→干脚气`（`干脚气 ⊃ 脚气`，Dice 恰好 0.8）、`藿香→广藿香`（Dice 0.8）、`湿热下注→湿热下注证`（Dice 0.889）。**只加 R2/R4 挡不住模糊级**（见 §2.4-6），子串等价一律由别名表决定（C3） |

> **为什么 `contain-delta` 取 1 而不是 2**：差 2 会放进两类**语义不等价**的包含命中 ——
> `知饥易饿 → 知饥不食`（清洗实测的负优化之一）、`带下量多 → 带下`（丢了「量多」限定）。
> 差 1 只放行「加一字修饰」的情形（`炒苍术→苍术`、`岷当归→当归`），这类基本是炮制/品名前缀。
> 高精度目标下，「差 2 的正确映射」应通过别名登记解决（可审计），而不是放宽阈值（靠猜）。

> **R2/R7 的代价（必须记账）**：`湿热下注→湿热下注证`、`藿香→广藿香` 这类「漏写后缀/简称」会被拒（R2 拦包含级，R7 拦模糊级）。补偿办法是把它们登记为对应标准词的别名（Task 10），而不是在判定里加"允许以证/症结尾""允许省略首字"之类的白名单 —— 依据 C3：语义等价由词典决定，不由代码猜。

```java
package com.tcm.ehr.common.utils;

/**
 * 术语语境护栏：判断一段术语原文是否处于「否证 / 已愈」语境。
 *
 * <p>为什么要独立成类：这条判据原先只写在 {@link EntityNormalizer}（解析链路），
 * 2026-10-18 实测发现清洗链路（{@code GovernanceServiceImpl.normalizeEntityList}）没有它 ——
 * 同一条 `无黄汗` 在解析链路被拦、在清洗链路被归成 `黄汗`（**语义反转**并写进导出件）。
 * 口径只写一处，两条链路共用。</p>
 *
 * <p>判据与 {@code EntityNormalizer} 原实现逐字相同（无/不/未/莫/非/缺/寡/忌/禁/欠 + 「已+痊愈」），
 * 已知代价也照旧：`不饥`/`不渴` 这类本身带否定的规范症状会被一起拦（它们在精确命中层不受影响）。</p>
 */
public final class TermGuard {

    private TermGuard() {
    }

    public static boolean isNegatedContext(String raw) {
        if (raw == null || raw.isEmpty()) {
            return false;
        }
        for (int i = 0; i < raw.length(); i++) {
            switch (raw.charAt(i)) {
                case '无': case '不': case '未': case '莫': case '非':
                case '缺': case '寡': case '忌': case '禁': case '欠':
                    return true;
                default:
                    break;
            }
        }
        int idx = raw.indexOf('已');
        if (idx >= 0 && idx + 1 < raw.length()) {
            String rest = raw.substring(idx + 1);
            for (String cured : new String[]{"愈", "好", "干净", "退", "消", "止", "解", "除", "去"}) {
                if (rest.startsWith(cured)) {
                    return true;
                }
            }
        }
        return false;
    }
}
```

```java
    /** 包含级允许的「输入比标准词长」上限（码点）：差得再远就不是同一个症状了（R3，默认 1） */
    @Value("${elasticsearch.contain-delta:1}")
    private int containDelta;

    private NormalizeResult judge(List<TermEntry> entries, String input) {
        // 1. 一级 A：标准词精确（跨全部候选，多条取最短）
        //    ⚠️ 分两轮而不是「逐条目先 std 再 alias」：后者会让更早召回的**别名**抢走
        //    本该由更短标准词精确命中的输入（实测 心悸 → 心悸手抖、知饥 → 知饥不食）。
        TermEntry best = null;
        for (TermEntry e : entries) {
            if (e.getStandardTerm() != null && e.getStandardTerm().equals(input)
                    && shorter(e, best)) {
                best = e;
            }
        }
        if (best != null) {
            return new NormalizeResult(best.getStandardTerm(), LEVEL_EXACT);
        }
        // 2. 一级 B：别名精确（同样分轮、同取最短标准词）
        for (TermEntry e : entries) {
            if (e.getStandardTerm() != null && e.getAliases() != null
                    && e.getAliases().contains(input) && shorter(e, best)) {
                best = e;
            }
        }
        if (best != null) {
            return new NormalizeResult(best.getStandardTerm(), LEVEL_EXACT);
        }
        // 3. R1：单字只允许精确命中（上面两轮已覆盖），不再参与包含/模糊
        int inputLen = input.codePointCount(0, input.length());
        if (inputLen < 2) {
            return null;
        }
        // 4. 二级·包含（R2 + R3 + R4）：只认「输入包含标准词/别名」这个方向，且差额受限于 containDelta
        TermEntry bestContains = null;
        for (TermEntry e : entries) {
            if (!containsAsPartOfInput(e, input, inputLen)) {
                continue;
            }
            if (shorter(e, bestContains)) {
                bestContains = e;
            }
        }
        if (bestContains != null) {
            return new NormalizeResult(bestContains.getStandardTerm(), LEVEL_CONTAIN);
        }
        // 5. 三级·模糊：字符 Dice ≥ 阈值，取最高分。
        //    ⚠️ R7 收紧：与输入构成「子串关系」的候选不参与打分 —— 否则 R2/R4 拦下的
        //    `脚气→干脚气`（Dice 恰好 0.8）、`藿香→广藿香`（0.8）会从模糊级复活。
        //    子串等价必须由别名表决定（C3）；模糊级只负责「形近但非子串」的错别字/变体。
        char[] inputDistinct = distinctChars(input);
        TermEntry bestFuzzy = null;
        double bestScore = 0;
        for (TermEntry e : entries) {
            if (hasSubstringRelation(e, input)) {
                continue;
            }
            double s = dicePrepared(inputDistinct, e.getStandardTerm());
            if (e.getAliases() != null) {
                for (String a : e.getAliases()) {
                    s = Math.max(s, dicePrepared(inputDistinct, a));
                }
            }
            if (s > bestScore) {
                bestScore = s;
                bestFuzzy = e;
            }
        }
        if (bestFuzzy != null && bestScore >= scoreThreshold) {
            return new NormalizeResult(bestFuzzy.getStandardTerm(), LEVEL_FUZZY);
        }
        return null;
    }

    /** 标准词/别名是否作为**完整片段**出现在输入里，且差额不超过 containDelta（R2~R4） */
    private boolean containsAsPartOfInput(TermEntry e, String input, int inputLen) {
        String std = e.getStandardTerm();
        if (std != null && !std.isBlank() && input.contains(std)
                && inputLen - std.codePointCount(0, std.length()) <= containDelta) {
            return true;
        }
        if (e.getAliases() == null) {
            return false;
        }
        for (String a : e.getAliases()) {
            if (a == null || a.isBlank()) {
                continue;
            }
            // 别名只在这个方向上认：输入里出现了完整的别名片段（R4 禁掉的是反方向）
            if (input.contains(a) && inputLen - a.codePointCount(0, a.length()) <= containDelta) {
                return true;
            }
        }
        return false;
    }

    /** 候选更短者优先（与改造前「多命中取最短标准词」同口径） */
    private static boolean shorter(TermEntry candidate, TermEntry best) {
        return best == null
                || candidate.getStandardTerm().length() < best.getStandardTerm().length();
    }

    /** 候选的 std / 任一别名是否与输入互为子串（R7：这类关系不许走模糊级，交给别名表） */
    private static boolean hasSubstringRelation(TermEntry e, String input) {
        if (substringEitherWay(e.getStandardTerm(), input)) {
            return true;
        }
        if (e.getAliases() != null) {
            for (String a : e.getAliases()) {
                if (substringEitherWay(a, input)) {
                    return true;
                }
            }
        }
        return false;
    }

    private static boolean substringEitherWay(String a, String input) {
        return a != null && !a.isBlank() && (a.contains(input) || input.contains(a));
    }
```

```python
CONTAIN_DELTA = 1


def _substring_either_way(e, term):
    """候选的 std / 任一别名是否与输入互为子串（R7）。"""
    parts = [e['standardTerm']] + list(e.get('aliases') or [])
    return any(p and (p in term or term in p) for p in parts)


def judge(entries, term):
    """三级判定（与 EsTermNormalizer.judge 同口径，含 R1~R4 + R6 + R7 护栏）。"""
    n = len(term)
    # 一级 A：标准词精确（多条取最短）—— 必须先于别名轮，见 R6
    cands = [e for e in entries if e['standardTerm'] == term]
    if cands:
        return min(cands, key=lambda e: len(e['standardTerm']))['standardTerm'], 1
    # 一级 B：别名精确（多条取最短）
    cands = [e for e in entries if term in (e.get('aliases') or [])]
    if cands:
        return min(cands, key=lambda e: len(e['standardTerm']))['standardTerm'], 1
    if n < 2:
        return None, 0
    # 二级：只认「输入包含标准词/别名」且差额 ≤ CONTAIN_DELTA（R2/R3/R4）
    best = None
    for e in entries:
        parts = [e['standardTerm']] + list(e.get('aliases') or [])
        if any(p and p in term and n - len(p) <= CONTAIN_DELTA for p in parts):
            if best is None or len(e['standardTerm']) < len(best['standardTerm']):
                best = e
    if best is not None:
        return best['standardTerm'], 2
    # 三级：Dice；R7 —— 与输入互为子串的候选不参与打分
    top, top_s = None, 0.0
    for e in entries:
        if _substring_either_way(e, term):
            continue
        s = dice(term, e['standardTerm'])
        for a in (e.get('aliases') or []):
            s = max(s, dice(term, a))
        if s > top_s:
            top, top_s = e, s
    if top is not None and top_s >= SCORE_THRESHOLD:
        return top['standardTerm'], 3
    return None, 0
```

```java
    /** 替换对的最小长度（码点）：单字替换只会污染文本，不给它机会（E1） */
    private static final int MIN_REPLACE_LEN = 2;
    /** 否定词窗口（同 TermGuard 的判据集合，这里只需前向 6 字） */
    private static final char[] NEG_CHARS = {'无', '不', '未', '莫', '非', '缺', '寡', '忌', '禁', '欠'};
    private static final int NEG_WINDOW = 6;

    /**
     * 按替换对做「受控」文本替换（E1~E3）。
     *
     * <p><b>为什么不能再用 {@code String.replace}</b>：它对每次调用做全文替换，且不区分位置 ——
     * 2026-10-18 实测一条病历里 `血 → 血分证` 命中 17 处（把「血行不畅」「血块」「经血色暗红」
     * 全改成「血分证行不畅」「血分证块」）、`有 → 有汗` 命中 11 处（「伴有腰酸痛」→「伴有汗腰酸痛」）。
     * 导出的标准数据集是要直接拿去分析/训练的，这种污染比"少替换一次"严重得多。</p>
     *
     * <p>扫描规则：① 丢弃码点 < {@link #MIN_REPLACE_LEN} 的对；② 对每个位置按 key 长度降序试匹配，
     * 命中即消费该区间（最长匹配 + 不重叠）；③ 命中位置前 {@link #NEG_WINDOW} 字含否定词则跳过。</p>
     */
    private static String standardizeText(String s, List<Map.Entry<String, String>> pairs) {
        if (s == null || s.isEmpty() || pairs.isEmpty()) {
            return s;
        }
        List<Map.Entry<String, String>> usable = new ArrayList<>();
        for (Map.Entry<String, String> p : pairs) {
            if (p.getKey().codePointCount(0, p.getKey().length()) >= MIN_REPLACE_LEN) {
                usable.add(p);
            }
        }
        if (usable.isEmpty()) {
            return s;
        }
        // 按 key 长度降序：最长匹配优先（与原注释里的「柴胡桂枝汤」案例同因，但这次是位置级保证）
        usable.sort((a, b) -> Integer.compare(b.getKey().length(), a.getKey().length()));
        StringBuilder out = new StringBuilder(s.length());
        int i = 0;
        while (i < s.length()) {
            Map.Entry<String, String> hit = null;
            for (Map.Entry<String, String> p : usable) {
                if (s.startsWith(p.getKey(), i)) {
                    hit = p;
                    break;
                }
            }
            if (hit == null) {
                out.append(s.charAt(i++));
                continue;
            }
            // 否定语境里的这一个落点不替换（否证句改了就成语义反转）
            if (negatedBefore(s, i)) {
                out.append(hit.getKey());
            } else {
                out.append(hit.getValue());
            }
            i += hit.getKey().length();
        }
        return out.toString();
    }

    /** 位置 pos 之前 NEG_WINDOW 字内是否有否定词（E3） */
    private static boolean negatedBefore(String s, int pos) {
        int from = Math.max(0, pos - NEG_WINDOW);
        for (int i = from; i < pos; i++) {
            char c = s.charAt(i);
            for (char neg : NEG_CHARS) {
                if (c == neg) {
                    return true;
                }
            }
        }
        return false;
    }
```
